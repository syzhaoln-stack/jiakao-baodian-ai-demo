# 木仓科技 · 驾考训练

题库、模拟考试与三维道路训练的浏览器演示。

- [打开题库与模拟考试](https://syzhaoln-stack.github.io/jiakao-baodian-ai-demo/)
- [打开三维道路训练增强版](https://syzhaoln-stack.github.io/jiakao-baodian-ai-demo/simulator/)

## 2026-09-22 更新

- 题库首页按需加载三维引擎；浏览器缓存固定版本题库，数据连接失败自动尝试备用线路，并提供重新加载入口。
- 模拟考试保留试卷、答案、未提交的多选选项和绝对截止时间；刷新或离开后可以继续，离开页面仍然计时。
- 提前交卷显示未答题数量并确认；未答计错，避免重复成绩记录，交卷后和成绩页均可复习本卷错题。
- 手机答题页增加直接交卷入口；无法写入浏览器存储时仍可继续答题，并提示进度无法保存。
- Blender 制作教练车、城市街区与道路资产，Godot 驱动单独的道路训练增强版；两种视角、触控驾驶、任务反馈。
- 增强版按点击进入后加载，不增加题库首页的引擎下载量。

## 已实现

- 6406 道原题：顺序、随机、搜索、专项、错题、收藏与答案解析；
- 判断、单选、多选、图片题和视频题；
- 100 题、45 分钟科目一模拟考试与成绩记录；
- 39 个知识专项，可从专项直接进入对应原题；
- 第一人称 AI 教练车：安全带、点火、P/R/N/D、左右转向灯、可拖动方向盘、油门、刹车、灯光与喇叭；
- 起步、变更车道、通过路口、靠边停车四项训练；
- 三个实时后视镜、车辆运动、交通信号灯、超速/压线/闯灯/碰撞判分、语音提示和音效；
- 武汉 / 湖北法规数字总览：限速、能见度、车距、禁停距离、记分和罚款的一张图；
- 可切换普通道路与高速 / 城市快速路的超速处罚计算器，并提供可打印版；
- 教练车“提示来源”说明，区分原题解析、浏览器语音、训练状态机和真实交通违法记分；
- 桌面端与手机端操作界面。

## 运行

在本目录启动本地服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173>。

增强版位于 <http://127.0.0.1:4173/simulator/>。首次进入需要下载 Godot 引擎资源，建议使用 Wi-Fi。学习记录保存在当前浏览器，不自动跨设备同步。

## 教练车操作

- `W` / `↑`：油门
- `S` / `↓` / `空格`：刹车
- `A` / `D`：转向
- `Q` / `E`：左右转向灯
- `H`：喇叭
- 也可以直接点击或拖动驾驶舱中的控件。

以下验证命令在完整本地工作区运行；公开演示仓库仅包含发布文件和三维源项目。


浏览器测试使用本机 Edge 和 Playwright；数据审计使用本地研究数据。Godot 项目与导出说明见 `godot-coach/README.md`。

## 发布维护

1. 在完整本地工作区重新导出 Godot Web 后，运行 `npm run prepare:pages`。
2. 脚本将发布文件同步到 `github-pages/jiakao-baodian-ai-demo/`，生成 `release.json` 文件清单与校验值。
3. 检查该 Git 仓库的变更后提交并推送 `main`，GitHub Pages 自动更新。

发布只包含应用与自制三维资源，不包含研究档案、题库副本、浏览器记录或本地缓存。线上题库和题目媒体继续从原公开来源的固定提交读取；使用条件见部署仓库的 `THIRD-PARTY-DATA-LICENSE.md`。这是一套学习演示，模拟训练反馈不等同于正式考试评分。
