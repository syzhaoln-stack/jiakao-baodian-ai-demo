# 驾考宝典 AI 训练系统

可直接运行的驾考学习与第一人称教练车演示。

## 功能

- 6406 道题：顺序、随机、搜索、专项、错题、收藏和解析
- 判断、单选、多选、图片题与视频题
- 100 题、45 分钟科目一模拟考试
- 39 个知识专项与题目映射
- 第一人称 AI 教练车：安全带、点火、P/R/N/D、转向灯、方向盘、油门、刹车、灯光和喇叭
- 起步、变更车道、通过路口、靠边停车训练
- 三个实时后视镜、车辆运动、交通信号灯和违规判分
- 桌面端与手机端界面
